# LearnMate AI — Your Adaptive Study Teacher 📚🤖

**An adaptive learning platform designed to help students learn concepts, practice questions, prepare for vivas, and improve their presentation skills.**

LearnMate AI aims to make learning more interactive and personalized by bringing multiple study tools together in one platform. Instead of simply reading notes, students can explore concepts, test their understanding, practice explaining answers, and review their performance.

## ✨ Features

### 📖 1. Learn — Interactive Learning
- Explore academic topics and understand concepts through explanations.
- Learn through examples and simplified descriptions.
- Support for different learning needs and difficulty levels.
- Language selection for a more accessible learning experience.

### 📝 2. Practice — Quiz-Based Learning
- Practice questions to test conceptual understanding.
- Interactive multiple-choice questions.
- Score-based feedback to identify knowledge gaps.
- Opportunities to review answers and practice again.

### 🎤 3. Mock Viva
- Practice answering viva questions on selected topics.
- Type answers or use voice input where supported.
- Review submitted answers and receive feedback.
- View a report highlighting performance, strengths, and areas for improvement.

### 🎥 4. Mock Presentation
- Practice delivering a presentation in a simulated environment.
- Use camera and microphone access where supported.
- Record and review presentation attempts.
- Receive feedback and recommendations to improve presentation delivery.

### 🤝 5. Study Buddy
- A collaborative learning space for students.
- Designed to support peer learning, shared study goals, and collaborative practice.

### 📊 6. Session History & Progress
- Review previous learning and practice sessions.
- Track assessment results where session data is saved.
- Use past performance to identify areas that need more attention.

> **Note:** Feature availability depends on the current implementation. AI-generated content, speech recognition, recording, persistence, and detailed evaluation may require additional integration or browser support. Only features verified in the deployed version should be described as fully functional.

## 🎯 Problem Statement

Students often use separate platforms for learning concepts, practicing questions, preparing for oral examinations, and improving presentation skills. This fragmented process makes it difficult to practice consistently and identify areas for improvement.

LearnMate AI brings these learning activities together in a single platform, with the goal of making academic preparation more interactive, accessible, and feedback-oriented.

## 💡 Our Solution

LearnMate AI provides a unified study environment where students can:

1. Learn a concept.
2. Practice questions related to that concept.
3. Test their understanding through a mock viva.
4. Practice presentation delivery.
5. Review available feedback and revisit weak areas.

The goal is to encourage **active learning rather than passive content consumption**.

## 🚀 Getting Started

### Option 1: Run the standalone HTML version

1. Clone or download this repository.
2. Locate the main HTML file.
3. Open it in a modern browser for basic functionality.
4. If camera or microphone access is required, run the project through a local development server or HTTPS.

For example, if Python is installed:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

Run this command from the folder containing the HTML file. If the project uses additional assets or a backend, follow the corresponding setup instructions instead.

### Option 2: Run the full project

If the repository includes a backend, package configuration, environment variables, or separate frontend files, follow the setup instructions for those components. Do not place private API keys directly in client-side JavaScript or commit them to GitHub.

## 🔐 Privacy & Limitations
